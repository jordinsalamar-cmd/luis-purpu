# Auditoría visual de Luis

Adapta los criterios de Impeccable, Taste Skill y las skills de animación solo cuando se toque la interfaz.

- Conserva el fondo negro, el grafo visible y la identidad visual Luis-Purpu.
- Prioriza legibilidad, jerarquía y contraste antes que adornos.
- Las animaciones del personaje deben comunicar estados reales y no bloquear la terminal.
- Revisa escalado, posición, movimiento, teclado, mouse, cierre limpio y consumo de CPU.
- No cree otra aplicación o página si el cambio pertenece al visor, overlay o terminal existente.
