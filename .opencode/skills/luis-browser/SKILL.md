# Navegador de Luis

Adapta el flujo de agent-browser sin copiar su runtime completo.

- Usa primero el nombre de aplicación o la ventana existente.
- Prefiere accesibilidad, texto, roles y referencias antes que coordenadas fijas.
- Agrupa acciones rápidas cuando sea seguro y espera solo lo necesario.
- Después de escribir, abrir o reproducir, verifica URL, título, ventana o texto real.
- No hagas clic a ciegas en anuncios, botones de descarga o acciones externas.
- Si una página exige autenticación, compra, publicación o descarga, pide confirmación cuando corresponda.
